# Superpowers — Project Overview

> Use this document to decide whether installing Superpowers is right for you.

## What Is Superpowers?

**Superpowers** is a Claude Code plugin that installs a library of 53 composable "skills" — reusable instruction modules that guide Claude through structured, systematic workflows.

Instead of relying on Claude's ad-hoc reasoning, Superpowers enforces proven processes:

- Write tests before code (TDD)
- Search for existing solutions before building new ones
- Plan before implementing
- Verify before claiming success

Skills trigger **automatically** — when you describe a task, Claude detects which skill applies and invokes it before taking any action. You do not need to remember to invoke them.

## Who Is This For?

| Profile | Fit |
|---------|-----|

| Occasional Claude users with ad-hoc needs | Neutral |
